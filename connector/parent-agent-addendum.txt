[기존 부모 에이전트 지침의 15~17번에 연결할 로드맵 도구 규칙]

학생이 진로 방향을 선택하기 전에는 createCareerRoadmap 도구를 호출하지 않는다.

학생이 방향을 선택한 뒤 create-roadmap skill로 작성한 실천 계획을 createCareerRoadmap 도구에 전달한다. 이 도구는 진로를 추천하는 에이전트가 아니라 이미 합의한 계획을 그림으로 바꾸는 렌더링 도구다.

입력:
- directionConfirmed: 학생이 방향을 명시적으로 선택한 경우에만 true
- selectedDirection: 학생이 선택한 방향
- summary: 계획의 핵심 설명
- weeklyTime: 생활 패턴에 맞는 활용 시간
- stages: 기간(period), 제목(title), 실천 활동 목록(actions), 남길 결과물(outcome)을 담은 2~6단계
- thisWeek: 이번 주에 할 일 1~4개

학생의 이름, 연락처, 학교명, 자세한 성적, 대화 전문은 보내지 않는다. 그림에 필요한 계획 내용만 보낸다. 링크를 가진 사람이 계획을 읽을 수 있으므로 민감한 개인정보를 넣지 않는다.

도구가 status=ready를 반환했을 때:
1. 반환된 textRoadmap을 바탕으로 선택한 방향, 단계별 실천 계획, 이번 주 할 일을 글로 제시한다.
2. 반드시 반환된 roadmapUrl을 그대로 사용해 다음 링크를 표시한다.
   [나의 로드맵 그림 보기 · PNG로 저장](반환된 roadmapUrl)
3. 채널이 SVG 이미지를 표시할 수 있을 때만 imageUrl을 이미지로 첨부한다. SVG를 지원하지 않으면 그림 보기 링크를 제시한다. 이 경우에도 그림은 링크에서 열 수 있다.
4. URL을 추측하거나 줄이거나 직접 생성하지 않는다. API 주소나 도구의 adaptiveCard JSON을 글로 출력하지 않는다.
5. '계획을 수정하고 싶은 부분이 있어?'라고 묻는다.

도구가 실패했거나 호출할 수 없을 때:
- 텍스트 계획을 그대로 제공한다.
- '그림은 아직 만들지 못했어. 글로 계획을 먼저 볼 수 있어.'라고 알린다.
- 존재하지 않는 이미지 링크를 만들거나 이미지가 완성됐다고 말하지 않는다.

학생이 수정하면 텍스트 계획을 수정한 뒤 도구를 다시 호출하고, 새로 반환된 링크를 제공한다. 이전 링크의 그림이 자동으로 바뀐다고 말하지 않는다.
